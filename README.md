## Genome Download and Galaxy Upload

The complete chloroplast genome of *Plumeria rubra* cultivar *Acutifolia* was obtained from the NCBI GenBank/Nucleotide database using accession **MN812495.1**. The genome sequence was downloaded in **FASTA format** and renamed **Plumeria_rubra_MN812495.1** before being uploaded to **UseGalaxy.org**.

The uploaded FASTA file was analyzed using the **Fasta Statistics** tool in Galaxy. The analysis showed a genome length of **153,912 bp** and **1 sequence record**. The tool also provided nucleotide statistics that were used for the analysis of the chloroplast genome.

## Gene Content and Important Observations

The chloroplast genome of *Plumeria rubra* cultivar *Acutifolia* contains **130 annotated genes**, including **85 protein-coding genes, 37 tRNA genes, and 8 rRNA genes**. Notable genes include **rbcL, psaA, psbA, atpA, petB, rpoB, rpl16, and matK**, which are involved in photosynthesis, energy production, transcription, and other chloroplast functions.

The genome also contains **intron-containing genes**, including **rpl2 and rpl16**, while **matK** is associated with the **trnK** region. Genes found within the inverted repeat (IR) regions are present in duplicated copies. The chloroplast genome has the typical **LSC–IR–SSC–IR** organization.
